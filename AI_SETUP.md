# 🤖 AI-Ассистент - Руководство по настройке

## 🎯 Что умеет AI-Ассистент?

### 1. ✨ Генерация проектов
Опишите проект своими словами, и AI создаст:
- Название и описание проекта
- Список задач с приоритетами
- Оценку времени на каждую задачу
- Рекомендации по выполнению

**Пример:**
```
Описание: "Создать интернет-магазин для продажи одежды с корзиной и оплатой"
AI сгенерирует: 8-10 задач с приоритетами и дедлайнами
```

### 2. 💬 Чат с AI
Задавайте вопросы и получайте советы:
- Как лучше организовать проект?
- Как расставить приоритеты?
- Советы по продуктивности
- Помощь в планировании

### 3. 📊 Анализ проектов (в разработке)
- Оценка прогресса
- Прогноз завершения
- Выявление проблем

## 🔑 Установка OpenAI API Key

### Шаг 1: Получите API Key

1. Зарегистрируйтесь на [OpenAI](https://platform.openai.com/)
2. Перейдите в [API Keys](https://platform.openai.com/api-keys)
3. Нажмите "+ Create new secret key"
4. Скопируйте ключ (начинается с `sk-...`)

### Шаг 2: Добавьте ключ в проект

Откройте файл `/backend/.env` и замените:

```env
# Было:
OPENAI_API_KEY=your_openai_api_key_here

# Станет:
OPENAI_API_KEY=sk-ваш_настоящий_ключ_здесь
```

### Шаг 3: Перезапустите Backend

```bash
# Остановите backend (Ctrl+C)
# Запустите снова:
cd /Users/dalersabirov/Desktop/шаблоны/backend
npm run dev
```

## 🚀 Как использовать

### 1. Генерация проекта

**В интерфейсе:**
1. Откройте **🤖 AI Assistant** в sidebar
2. Выберите "✨ Генерация проекта"
3. Опишите проект:
   ```
   Создать систему бронирования для отеля с:
   - Поиском свободных номеров
   - Онлайн оплатой
   - Личным кабинетом
   - Управлением для админов
   ```
4. Нажмите "Сгенерировать проект"
5. Проверьте результат
6. Нажмите "✅ Создать этот проект"

**Через API:**
```bash
curl -X POST http://localhost:5001/api/ai/generate-project \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Создать мобильное приложение для фитнес-трекинга",
    "preferences": "Срок - 2 месяца, команда из 3 человек"
  }'
```

### 2. Чат с AI

**В интерфейсе:**
1. Откройте **🤖 AI Assistant**
2. Выберите "💬 Чат с AI"
3. Задайте вопрос:
   - "Как лучше спланировать проект на 3 месяца?"
   - "У меня 5 задач, какие сделать первыми?"
   - "Как повысить продуктивность команды?"

**Через API:**
```bash
curl -X POST http://localhost:5001/api/ai/chat \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Как лучше организовать задачи в проекте?"
  }'
```

## 🛠 Технические детали

### Модель: GPT-3.5-turbo
- Быстрая и доступная
- Хорошо понимает русский
- Подходит для большинства задач

### Параметры:
```javascript
{
  model: "gpt-3.5-turbo",
  temperature: 0.7,  // Креативность (0-1)
  max_tokens: 2000   // Максимум слов в ответе
}
```

### Для обновления на GPT-4:
В файле `backend/controllers/aiController.js` замените:
```javascript
model: "gpt-3.5-turbo"  →  model: "gpt-4"
```
⚠️ GPT-4 дороже (~$0.03-0.06 за генерацию проекта)

## 🚨 Troubleshooting

### "Ошибка генерации проекта"

**Причина 1:** Неверный API ключ
```bash
# Проверьте .env файл:
cat backend/.env | grep OPENAI_API_KEY

# Должно быть: OPENAI_API_KEY=sk-...
```

**Причина 2:** Закончились средства на OpenAI
- Проверьте баланс: https://platform.openai.com/account/billing
- Пополните счет

**Причина 3:** Превышен rate limit
- Подождите 1 минуту
- Или обновите тарифный план

### "Cannot find module 'openai'"

```bash
cd backend
npm install
```

### AI возвращает странный ответ

Обновите промпт в `backend/controllers/aiController.js`
Сделайте его более конкретным
