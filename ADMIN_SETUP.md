# 👑 Настройка администратора

## 🎯 Как создать первого администратора

### Вариант 1: Через MongoDB Compass (Графический интерфейс)

1. **Скачайте и установите MongoDB Compass**
   - https://www.mongodb.com/try/download/compass

2. **Подключитесь к базе данных**
   - URL: `mongodb://localhost:27017`
   - Database: `datalens`

3. **Найдите коллекцию `users`**

4. **Найдите нужного пользователя и измените его роль**
   - Найдите поле `role`
   - Измените значение с `"user"` на `"admin"`
   - Сохраните изменения

### Вариант 2: Через MongoDB Shell (Терминал)

```bash
# 1. Откройте MongoDB shell
mongosh

# 2. Переключитесь на базу datalens
use datalens

# 3. Просмотрите всех пользователей
db.users.find().pretty()

# 4. Сделайте пользователя администратором (по email)
db.users.updateOne(
  { email: "ваш@email.com" },
  { $set: { role: "admin" } }
)

# 5. Проверьте изменения
db.users.findOne({ email: "ваш@email.com" })

# Должно показать: role: 'admin'
```

### Вариант 3: Регистрация с автоматическим admin правом

Если вы первый пользователь, можете временно изменить код:

**В файле** `backend/controllers/authController.js`:

Найдите строку в функции `register`:
```javascript
const user = await User.create({ name, email, password });
```

Временно замените на:
```javascript
const user = await User.create({ 
  name, 
  email, 
  password, 
  role: 'admin'  // 👈 Добавьте эту строку
});
```

После регистрации **ОБЯЗАТЕЛЬНО ВЕРНИТЕ КОД ОБРАТНО!**

## 📊 Что включает админ-панель?

### 1. Статистика системы 📈
- Общее количество пользователей
- Количество досок, задач, файлов
- Новые пользователи за месяц
- Активность за сегодня
- Топ-5 самых активных пользователей

### 2. Управление пользователями 👥
- Просмотр всех пользователей
- Изменение ролей (user ↔ admin)
- Просмотр статистики каждого пользователя:
  - Количество досок
  - Количество задач
  - Общая активность
- Удаление пользователей
- Дата регистрации и последнего входа

### 3. Логи активности 📝
Отслеживание всех действий пользователей:
- 🔐 **Вход в систему** (login) - кто, когда, откуда
- ✨ **Регистрация** (register)
- 👋 **Выход** (logout)
- 📋 **Создание доски** (create_board)
- ✏️ **Обновление доски** (update_board)
- 🗑️ **Удаление доски** (delete_board)
- ➕ **Создание задачи** (create_task)
- 📝 **Обновление задачи** (update_task)
- ❌ **Удаление задачи** (delete_task)
- 📤 **Загрузка файла** (upload_file)
- 🗑️ **Удаление файла** (delete_file)

Для каждого действия записывается:
- Пользователь (имя, email)
- Тип действия
- Детали действия
- IP адрес
- User-Agent (браузер)
- Дата и время

## 🔐 Как войти как администратор

1. **Зарегистрируйтесь** в системе (или войдите)
2. **Сделайте себя админом** (см. инструкции выше)
3. **Выйдите и войдите снова** (чтобы токен обновился)
4. **В Sidebar появится кнопка "Admin"** 🛡️
5. **Нажмите на неё** - откроется админ-панель

## 📡 API Endpoints для администратора

Все эти endpoints требуют:
- Авторизацию (JWT токен)
- Роль `admin`

```
GET  /api/admin/stats              - Статистика системы
GET  /api/admin/users              - Список всех пользователей
GET  /api/admin/activity           - Логи активности
GET  /api/admin/users/:id/activity - Активность пользователя
PUT  /api/admin/users/:id/role     - Изменить роль пользователя
DELETE /api/admin/users/:id        - Удалить пользователя
GET  /api/admin/activity/chart     - График активности
```

### Примеры запросов:

**Получить статистику:**
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:5001/api/admin/stats
```

**Сделать пользователя админом:**
```bash
curl -X PUT \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"role":"admin"}' \
  http://localhost:5001/api/admin/users/USER_ID/role
```

**Получить логи входов:**
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "http://localhost:5001/api/admin/activity?action=login&limit=50"
```

## 🔍 Примеры использования

### Кейс 1: Узнать кто входил сегодня

1. Откройте админ-панель
2. Перейдите в "Активность"
3. Отфильтруйте по действию "login"
4. Увидите все входы с IP адресами и временем

### Кейс 2: Найти самых активных пользователей

1. Откройте админ-панель
2. На вкладке "Статистика"
3. Смотрите секцию "Топ активных пользователей"

### Кейс 3: Проверить что делал конкретный пользователь

1. Перейдите в "Пользователи"
2. Найдите нужного пользователя
3. Нажмите "Подробнее" или используйте API:
   ```
   GET /api/admin/users/:userId/activity
   ```

### Кейс 4: Забанить пользователя

1. Перейдите в "Пользователи"
2. Найдите нужного пользователя
3. Нажмите "🗑️ Удалить"
4. Подтвердите действие

**Внимание!** Это удалит:
- Пользователя
- Все его доски
- Все его задачи
- Все его файлы
- Все логи активности

## 🛡️ Безопасность

### Что защищено:
- ✅ Только администраторы могут видеть админ-панель
- ✅ API проверяет роль на каждом запросе
- ✅ Нельзя удалить свой собственный аккаунт
- ✅ Все действия логируются с IP адресами

### Рекомендации:
- Не делайте всех пользователей админами
- Регулярно проверяйте логи активности
- Следите за подозрительными входами
- Используйте сильные пароли
