# Datalens - Система управления проектами

## 🚀 Что было реализовано

### ✅ Аутентификация и регистрация
- **Полнофункциональная система входа и регистрации**
  - Валидация полей (email, пароль минимум 6 символов)
  - Проверка существующих пользователей
  - Автоматический вход после регистрации
  - Сохранение данных в localStorage
  - Отображение ошибок для пользователя

### 🎨 Внутренняя часть приложения (Dashboard)
После успешной регистрации/входа пользователь попадает в полнофункциональный dashboard с:

#### 1. **Home (Главная страница)**
- Приветствие пользователя по имени
- Статистика в карточках:
  - Активные проекты
  - Файлы
  - Участники
  - Завершенные задачи
- Лента недавней активности

#### 2. **Boards (Доски)**
- Сетка с карточками досок
- Таблица со всеми досками
- Возможность создания новых досок
- Цветовая индикация для каждой доски
- Отображение количества задач

#### 3. **Files (Файлы)**
- Сетка с карточками файлов
- Таблица со всеми файлами
- Информация о типе, размере и дате файлов
- Возможность загрузки новых файлов

#### 4. **Settings (Настройки)**
- Информация профиля с аватаром
- Настройки уведомлений (Push, Email)
- Переключатель темной темы
- Редактирование профиля

### 🎯 Боковая панель (Sidebar)
- Анимированная боковая панель с двумя уровнями
- Аватар пользователя с первой буквой имени
- Навигация между разделами
- Кнопка выхода с подтверждением
- Отображение имени пользователя

## 🛠 Технологии
- React 19.2.4
- Context API для управления состоянием
- localStorage для хранения данных
- Akar Icons для иконок
- CSS3 с анимациями и transitions

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск приложения
npm start
```

Приложение откроется на `http://localhost:3000`

## 🔐 Как использовать

### Регистрация нового пользователя:
1. Нажмите кнопку "SIGN UP" на странице входа
2. Заполните форму:
   - Имя
   - Email
   - Пароль (минимум 6 символов)
3. Нажмите "SIGN UP"
4. Вы автоматически войдете в систему

### Вход в систему:
1. Введите email и пароль
2. Нажмите "SIGN IN"
3. Вы попадете в dashboard

### Навигация:
- Наведите курсор на боковую панель для расширения
- Кликайте на иконки для переключения между разделами
- Используйте кнопку выхода (красная иконка внизу) для выхода
